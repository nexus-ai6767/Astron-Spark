Quick start

  1. Download JARVIS_PC_RELEASE.zip from the downloads section and extract it to a folder you control.
  2. Install the prerequisites: Python 3.11 or newer and Ollama. Then pull the local model the release uses: 
    ollama pull qwen2.5:1.5b
  3. Install the packages: double-click install.bat. It installs the Python packages listed in requirements.txt.
  4. Launch: double-click start_jarvis.bat, allow microphone and camera access when Windows asks, then say or type a command.

Before you run anything, verify the checksum of the file you downloaded.

What’s included in the PC release

  • main.py — the ASTRON application
  • install.bat — installs the Python packages
  • start_jarvis.bat — starts ASTRON
  • requirements.txt — the package list
  • README.txt — short offline instructions

All of these are plain text files. Open them in a text editor and read them before you run anything.

Starter edition

The Starter zip is the beginner/source edition for learning the foundations of a personal AI assistant: a voice assistant, local AI through Ollama, notes and memory, and basic PC commands. It needs the same Python and Ollama prerequisites.

Android app

The Android app runs a small AI model on the phone itself. Download the APK from the Android section and follow Android’s install prompts. The current build is a debug build for early testers, so Android may ask you to allow installs from your browser or file manager. Only install it from this site or the official GitHub release.

Troubleshooting

“python” is not recognised

Reinstall Python and tick Add python.exe to PATH on the first screen, then run install.bat again.

ASTRON starts but gives no answers

Check that Ollama is running and that the model is installed:

ollama list

If qwen2.5:1.5b is missing, run ollama pull qwen2.5:1.5b.

Windows shows a SmartScreen or “unknown publisher” warning

The scripts are not code-signed. That is expected for plain .bat and .py files. Verify the checksum, read the files, and continue only if you are comfortable.

The microphone or camera does not work

Open Windows Settings → Privacy & security and make sure microphone and camera access is allowed for desktop apps. Close other apps that may be using the device.

Verify your download

A checksum is a fingerprint of a file. If the fingerprint you compute matches the one published on the downloads section, the file is exactly what was published. If it differs, delete the file and download it again.

Windows PowerShell

Get-FileHash .\JARVIS_PC_RELEASE.zip -Algorithm SHA256

Windows Command Prompt

certutil -hashfile JARVIS_PC_RELEASE.zip SHA256

macOS / Linux

sha256sum JARVIS_PC_RELEASE.zip

A checksum proves the file was not altered after publishing. It does not prove the software is harmless, so also read the scripts. The Android APK’s checksum is not published yet; compare it on the GitHub release page.
