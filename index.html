Get running

From zero to ASTRON.

Four steps from download to your first spoken command. Need more detail? See the full setup guide.

  1. 01

    Download

    Get the ASTRON PC release and extract it to a folder you control.

    JARVIS_PC_RELEASE.zip
  2. 02

    Prerequisites

    Install Python 3.11+ and Ollama, then pull the local model the release uses.

    ollama pull qwen2.5:1.5b
  3. 03

    Install

    Double-click the installer to add the required Python packages.

    install.bat
  4. 04

    Launch

    Start ASTRON, allow microphone and camera permissions, then test a command.

    start_jarvis.bat

How to verify a download

After downloading, compute the file’s SHA-256 and compare it with the value above. If the two differ, delete the file and download it again from this page.

Windows (PowerShell)

Get-FileHash .\JARVIS_PC_RELEASE.zip -Algorithm SHA256

Windows (Command Prompt)

certutil -hashfile JARVIS_PC_RELEASE.zip SHA256

macOS / Linux

sha256sum JARVIS_PC_RELEASE.zip

Stay safe

  • Download only from this page or the official GitHub release.
  • The installers are plain .bat and .py text files — open them in a text editor and read them before you run anything.
  • The scripts aren’t code-signed, so Windows may show a warning. Checking the checksum first is the right move.
  • ASTRON can control your PC, microphone and camera. Enable each module deliberately.

Common questions

Before you activate.

Does ASTRON send my data to the cloud?

Not by default. ASTRON is built to run against a local model through Ollama, so conversations and commands stay on your machine unless you choose to connect an external service.

What operating systems are supported?

The current release targets Windows for gesture control, automation and system-level commands. Voice and local-AI features work more broadly — check the README in the release download for details.

Do I need a powerful computer?

It depends on which local model you connect. Smaller models run comfortably on modest hardware; larger ones benefit from a dedicated GPU. ASTRON itself is lightweight.

What’s the difference between Core, Starter and Pro?

Core is the free, self-configured community version and Starter is a gentler beginner edition. Pro is the full Windows application with Vision, Voice, the Smart Command Engine, Serious Mode, local AI and OCR. Done-for-you setups are available through the custom build form.

Can I request a feature that isn’t listed?

Yes — use the custom build form below and describe what you’re trying to do. Most requests are scoped as part of a custom build.
